# DSH Probes

两个**只读**排障探针，都来自一次真实的凌晨排查。那次的事故一句话就能说完：

> 有人为了让 DSH 走代理，把 `HTTP_PROXY` 写进了**用户级持久环境变量**。
> 几天后的某个深夜，Clash 一关 —— DSH 连不上模型了，
> 连跟 DSH 毫无关系的**两款游戏的登录器**也双双报网络错误。

| 文件 | 是什么 |
|---|---|
| [`proxy-doctor.cjs`](proxy-doctor.cjs) | 代理体检三合一：三层代理变量 / 端口探活 / 「走代理 vs 强制直连」对照 / 考古谁写过代理变量 |
| [`asar-probe.cjs`](asar-probe.cjs) | 在 DSH 的 `app.asar` 里按关键词捞官方包 README 与源码，无需解包 |

**两者都是只读的**：不改配置、不写文件；只有 `proxy-doctor route` 会向**你自己给的那个 URL** 发一次请求。

需要 Node.js 18+（`route` 子命令用的是内置 `fetch`）。零依赖。

---

## 1. `proxy-doctor.cjs` —— 「某个程序一关代理就断网」

**典型症状**：不是超时，是**瞬间失败**（连接被拒，几毫秒）—— 而网络本身完全健康
（DNS 正常、路由正常、防火墙没有拦截、浏览器也上得去网）。真因往往是一个你看不见的代理变量，
把请求送进了一个**已经没人监听**的端口。

```bash
node proxy-doctor.cjs env                        # 三层代理变量 + 系统代理 + 端口探活
node proxy-doctor.cjs route https://example.com  # 走代理 vs 强制直连，各发一次
node proxy-doctor.cjs writes                     # 考古：哪个会话/命令写过代理变量（DSH 专用）
```

**判读**：`route` 里 `[1]`（按当前环境路由）失败、而 `[2]`（强制直连）成功
⇒ 有个代理在挡路，而且那台机器上**没人监听它**。

### 为什么"读三层"很重要

同一个名字可能同时存在于**进程继承的环境**、**用户级持久变量**、**某个程序自己的配置文件**里，
而它们的优先级不一样、生效时机也不一样。只查一层，很容易得出"我明明改对了却没用"的错误结论。

## 2. `asar-probe.cjs` —— 「DSH 内部到底怎么做的」

Electron 应用的 `app.asar` 里带着**每个官方包的完整 README（英中双语）与源码**，
它比任何二手资料都权威。`asar-probe.cjs` 让你**不必解包那 121 MB** ——
asar 自带 JSON 索引、内容可随机读取，按关键词定位就够了。

```bash
node asar-probe.cjs find NO_PROXY dsh-http-proxy   # 关键词的命中偏移
node asar-probe.cjs read 51725000 4000            # 从某偏移读一段原文
```

asar 路径的解析顺序：

1. `--asar <path>` 命令行参数
2. 环境变量 `DSH_ASAR`
3. 常见安装位置（Windows / macOS / Linux 各几个候选）

例：`node asar-probe.cjs --asar "D:\Somewhere\app.asar" find proxy`

> 顺带一提：那次排查的转折点就是用这个工具在 asar 里翻出了官方 `dsh-http-proxy` 包的文档 ——
> 它白纸黑字写着代理策略**覆盖 LLM 流量**、`NO_PROXY` 是**后缀匹配**
> （`NO_PROXY=example.com` 连 `api.example.com` 一起放行）。
> **不用猜、不用搜二手资料，读它自己的文档。**

## 那次排查留下的两条判据

1. **代理配置的「作用域」要主动选。**
   用户级持久环境变量会影响这台机器上**每一个**读它的程序 —— 不只是你想帮的那一个
   （那次连游戏登录器都被裹进了代理）。要让某个程序走代理，优先用**该程序自己的配置层**，
   或**单命令显式指定**。
2. **修好配置后，已经在跑的进程不会自己更新。**
   环境变量是"出生时"继承的：改完必须重启那个进程（或注销/重启一次），
   否则你会以为"改了没用"。**验证小技巧**：新开一个终端敲 `echo %HTTP_PROXY%`（Windows）
   或 `echo $HTTP_PROXY` —— 原样回显变量名 = 它已经不存在了。
